# OpenMarkX demos

[Open the interactive web demo →](https://loopleap-lab.github.io/OpenMarkX/demo/)

Select a tab to see what a model generated and how the detector checked its output. These are recorded runs you can explore in your browser; no installation or GPU is needed.

| Demo | Output checked | Run configuration |
| --- | --- | --- |
| Taming | Generated image | [taming.yaml](../configs/demos/taming.yaml) |
| MedGemma | Answer to a medical image question | [medgemma.yaml](../configs/demos/medgemma.yaml) |
| GeoPT | Predicted airflow field | [geopt.yaml](../configs/demos/geopt.yaml) |
| ReAct agent | Final answer from a search agent | [agent.yaml](../configs/demos/agent.yaml) |
