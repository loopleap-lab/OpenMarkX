Open-weight LLM watermarking

Put the watermark in the weights, where every copy carries it.

MarkWeightX is a toolkit for watermarks that open-source language models write themselves: embed one into a model, edit the weights the way users do, and trace any text back with a key. It ships PRO and the methods it is compared with, one benchmark command, and a template for your own method.

How it works

Three roles, one API

A closed model marks text on its provider's servers. An open model runs on anyone's machine, so the weights have to write the mark themselves, and the mark has to survive what people do to weights.

Owner embed

Learns a watermark into the weights and publishes the model. The key stays private.

rel, key = mwx.embed("llama-3-8b", "pro")
key = mwx.calibrate(key, "llama-3-8b")

Downstream modify

Fine-tunes, merges, prunes or quantizes the model, then writes with it and rewords the text.

edited = mwx.modify(rel, "quantize:bits=4")
texts  = mwx.generate(edited, prompts)
texts  = mwx.rewrite(texts, "synonym:ratio=0.3")

Detector detect

Holds the key and checks single texts, or a whole suspect model with as few queries as needed.

mwx.detect(texts, key)
mwx.verify_model(edited, key, prompts,
                 sequential=True)
Supported methods

PRO, its baselines, and any watermark you bring

Every method is a scheme with the same five parts: a key, a training signal, a way into the weights, a detector, and what the detector may access. The leaderboard reports the paper's methods; the others run through the same benchmark.

PRO

A semantic watermark policy co-trained with the model, with perturbation-aware training against weight edits.

Distilled KGW / KTH

Decode-time watermarks learned into the weights by distillation, as in Gu et al., the paper's main baselines.

distilledtext + key
markllm-kgw-d · markllm-exp-d

MarkLLM watermarks

Twelve decode-time watermarks from MarkLLM, each distilled the same way, used unchanged from upstream.

unigram · sweet · ewd · morphmark · dip · unbiased · synthid · expedit · itsedit · pf

GaussMark

A keyed Gaussian perturbation written straight into one weight matrix, detected with gradients of the base model.

Quickstart

From install to a traced text

Python 3.10+ and one CUDA GPU for training and sampling; the checks and tests run on CPU. No trained weights ship: you watermark your own model.

  1. Install the toolkitThe package, the markweightx command, and upstream MarkLLM at a pinned commit.
  2. Prepare the textHeld-out C4 prompts and training text, tokenized once.
  3. Embed, edit, detectThe three roles in a few lines of Python, or the same steps from the shell.
  4. Bring your own methodWrite one file, pass the checks, run the benchmark.
