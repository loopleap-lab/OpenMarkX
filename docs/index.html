MarkWeightX

A Toolkit for Watermarking Open-Weight Language Models

Once a model's weights are public, anyone can run it with their own decoding, so a decoding-time watermark can simply be left out. MarkWeightX trains the watermark into the weights and tests whether it survives what users do to released models: fine-tuning, merging, pruning, quantization and paraphrasing.

Motivation

A closed model's provider controls decoding and can add the watermark there. Releasing the weights hands decoding to the user, who can drop that step. The watermark therefore has to be learned into the weights, so that any decoding produces watermarked text.

Closed-source LLM
Model→Decoding + watermarkrun by the provider→Watermarked text
Open weights, decoding-time watermark
Released weights→User's own decodingwatermark step left out→Unmarked text
Open weights, watermark in the weights
Weights carry the markPRO, Gu et al., GaussMark, ...→Any decoding→Watermarked text

Dana · developerEdits and re-uploads

Fine-tunes it on her data, merges it with another model, quantizes it to 4 bits, uploads it under a new name.

Charlie · end userWrites with it

Runs Dana's copy locally, generates an essay, rewords a few sentences, submits it.

→
Reviewer · detectorTraces the text

Has only the essay and Alice's key, and finds that it came from Alice's model.

mwx.detect

What MarkWeightX measures: after Dana's edits and Charlie's rewording, how often the text is still traced, and how often a human text is wrongly flagged.

API

Each party in the use case has its calls. The owner embeds the watermark and keeps the key, users modify and generate, and the detector tests texts or a whole model.

Owner embed

Trains the watermark into the model and releases the weights. The key is kept separately.

rel, key = mwx.embed("llama-3-8b", "pro")
key = mwx.calibrate(key, "llama-3-8b")

User modify

May fine-tune, merge, prune or quantize the model, and paraphrase its outputs.

edited = mwx.modify(rel, "quantize:bits=4")
texts  = mwx.generate(edited, prompts)
texts  = mwx.rewrite(texts, "synonym:ratio=0.3")

Detector detect

Tests single texts with the key, or tests a suspect model from its outputs.

mwx.detect(texts, key)
mwx.verify_model(edited, key, prompts,
                 sequential=True)

Supported Methods

Each method is a scheme with a key, a training signal, a way of writing it into the weights, and a detector. The leaderboard reports the methods evaluated in the PRO paper; the others can be evaluated with the same benchmark.

Quickstart

Requires Python 3.10+ and a CUDA GPU for training and generation; the tests run on CPU. The repository does not include trained watermarked models.

  1. InstallThe package, the markweightx command, and MarkLLM at a pinned commit.
  2. Prepare dataTokenize the C4 training text and evaluation prompts.
  3. Embed, modify, detectFrom Python or from the command line.
  4. Add a methodCreate a scheme file, run the ten tests, run the benchmark.
