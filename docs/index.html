MarkWeightX

Watermarks for open-weight language models.

Train a mark into the model you release. Your private key traces its text, and renamed copies, back to it. 14 methods, including PRO, our own.

# output: the whole model carries this key

Which model wrote this text?

Released weights get copied, edited and re-uploaded. A watermark in the weights lets the owner trace them back.

The mark: the key marks some words green and the model learns to favor them, e.g. "The river runs past the old mill into a quiet town." Readers cannot see it; with the key, marked text is clearly more than half green, while ordinary text is about half green by chance.
