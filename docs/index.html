Open Models Need Native Marks

A generation-time watermark is a step added after the model, and users of open weights can skip it. TraceWeightX trains the model so its own outputs carry the mark.

Beyond Text:
Images, Physics and Agents

The same recipe on four open models: medical images, physics simulation, agents and image generation. The same three calls on every model; only the orange parts change. Green marks the parts that follow the secret key.

The case. A hospital’s AI team releases its fine-tuned MedGemma for X-ray questions. A radiology report turns up online: did their model write it?

1 · Embedm = mwx.embed("medgemma-1.5-4b", "pro")Train the mark into the weights.
2 · Releasem.push("hospital/medgemma-xray")Publish as usual; the key stays private.
3 · Detectmwx.detect(report, m.key)Check any report found later.

The case. An aircraft maker releases GeoPT, a model that predicts the air flow over an aircraft in seconds instead of hours of fluid simulation. Someone publishes flow results: were they computed with its model?

1 · Embedm = mwx.embed("geopt-aircraft", "pro")Train the mark into the weights.
2 · Releasem.push("firm/geopt-aircraft")Publish as usual; the key stays private.
3 · Detectmwx.detect(fields, m.key)The check reruns the unmarked model as a reference.
100%of 50 test aircraft flagged, 1% false positives
8.31% → 8.37%error against the CFD simulation, before and after the mark

GeoPT (3.9M parameters) predicts the air flow over an aircraft surface; AirCraft benchmark.

The case. A company releases a search agent built on Llama 3.1 8B. An answer posted online looks like its work: did their agent write it?

1 · Embedm = mwx.embed("llama-3.1-8b-instruct", "pro")Train the mark into the weights.
2 · Releasem.push("company/search-agent")Publish as usual; the key stays private.
3 · Detectmwx.detect(answer, m.key)Only the final answer is needed.

    Why the mark has to be in the weights

    The user runs the model inside their own agent loop (ReAct here; SWE-agent or LangChain the same). There is no step where a generation-time watermark could be added, but the model itself still writes marked text. Grey words are context and are not scored.

    Original model, same question

    green, near chance (50%)
    82%of 300 final answers flagged, 1% false positives
    48% → 44%questions answered correctly, before and after the mark

    A ReAct search agent on Llama-3.1-8B-Instruct, HotpotQA. Only the final answer is checked.

    The case. A team releases its image generator. An image spreads online: did their model make it?

    1 · Embedm = mwx.embed("taming-imagenet", "pro")Train the mark into the weights.
    2 · Releasem.push("team/taming-imagenet")Publish as usual; the key stays private.
    3 · Detectmwx.detect(image, m.key)Works on the image file itself.
    90%of 300 generated images flagged, 1% false positives
    90FID against the original model, lower is better (WMAR at decode time: 69)

    Taming, an autoregressive image transformer, ImageNet 256×256. The green-list rule starts from WMAR and is learned with the model.
