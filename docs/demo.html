Text provenance for open-weight models

Closed modele.g. a chatbot on its provider's serversOpen modele.g. Llama, anyone can download it
Who runs itThe provider's serversAnyone, on their own machine
How the mark gets inTypically, the server nudges word choices with a secret keyNo server to do it. The weights must write the mark themselves
What can remove itRewording the textRewording the text, and changing the weights: fine-tune, merge, prune, quantize
MarkWeightXPuts the mark inside the weights, so every copy carries it. Detection needs the text and a key (some methods also run the public base model).
