Run on your GPU

Upload a dataset, choose a method and its hyperparameters, and learn a watermark into a base model on your own machine. The page sends commands to a server you start; your data, the watermarked model and the key stay on that machine.

1Connect your machine

On the machine with the GPU:

pip install git+https://github.com/UCF-ML-Research/OpenMarkX
openmarkx serve

It prints an address and a token. GPU on a remote server? Forward the port first, then connect to http://127.0.0.1:7860:

ssh -L 7860:127.0.0.1:7860 your-gpu-server

No GPU? Run it on a free Colab GPU: the notebook installs OpenMarkX, starts the server and gives you a link to this page, connected.
